# Nature Language Guardrails

Use this reference for manuscript prose, abstracts, titles, figure legends, and summary paragraphs.

## Section Moves

| Section | Main Job | Preferred Move Order | Avoid |
| --- | --- | --- | --- |
| Title | Make the paper searchable, accurate, and defensible | entity/process + mechanism/context/outcome | vague hooks, unsupported `first`, stacked jargon |
| Abstract | Let editorial readers understand context, gap, approach, result, and implication | context -> gap -> approach -> key result -> implication | exhaustive methods, inflated novelty, unsupported mechanism |
| Introduction | Explain why the topic matters and what gap the study addresses | importance -> known work -> gap -> study aim -> value or approach | detailed results, long historical throat-clearing |
| Results | Report what was observed and under which condition | orient to figure/experiment -> observation -> quantitative detail -> comparison | discussion-length mechanism claims |
| Discussion | Explain meaning and boundary | main finding -> plausible explanation -> prior work -> limitation -> implication | repeating results, causality from association |
| Methods | Make work reproducible | design/cohort -> materials/data -> procedure -> outcomes -> analysis/statistics -> ethics | `routine methods`, `standard conditions`, vague statistics |
| Figure legend | Let the figure be interpreted without overloading the page | panel identity -> visual encoding -> assay/sample -> statistic or scale -> abbreviation definitions | unreported tests, unexplained symbols, long interpretation |

## Sentence Control

- Aim for 10-30 words per sentence.
- Split a sentence if it contains two independent claims or a claim plus a full interpretation.
- Keep one main subject-verb proposition per sentence where possible.
- Prefer active scientific verbs when the actor matters: `we developed`, `we identified`, `we quantified`.
- Use passive voice when the method or observation matters more than the actor.
- Avoid rhetorical questions, contractions, and conversational fillers.

## Hedging Ladder

| Strength | Use When | Example Verbs |
| --- | --- | --- |
| Strong evidence | Direct experiment or replicated quantitative result | `show`, `demonstrate`, `establish` |
| Moderate evidence | Consistent pattern or supported association | `suggest`, `indicate`, `support` |
| Mechanistic possibility | Plausible but not directly proven | `may reflect`, `could indicate`, `is consistent with` |
| Boundary or uncertainty | Incomplete evidence or context dependence | `requires further study`, `should be interpreted with caution` |

Do not upgrade association to causation. Do not turn method performance into biological mechanism.

## Overclaim Checks

Flag and soften:

- `prove`
- `conclusively`
- `unprecedented`
- `best`
- `superior`
- `first`
- `for the first time`
- `universal`
- `paradigm-shifting`

Safer alternatives include:

- `show`
- `suggest`
- `to our knowledge`
- `in this cohort`
- `among the strongest`
- `under these conditions`

## House Style Defaults

- Use British spelling for Nature-style prose unless the target journal or user says otherwise.
- Use numerals for measurements and leave a space between number and unit.
- Define abbreviations on first use.
- Keep statistical symbols and units unchanged.
- Preserve gene names, protein names, model names, chemicals, Greek letters, and citation markers.
- Do not invent citations, datasets, mechanisms, sample sizes, p values, or software versions.
