# Review Writing Framework

综述写作优先解决结构，而不是先润色句子。

输出结构：

1. `Scope`: 主题、疾病/系统、方法类别、时间范围和排除项。
2. `Taxonomy axes`: 按数据模态、方法类别、生物学问题、证据等级或转化阶段分类。
3. `Evidence matrix`: 主张、证据来源、状态和局限。
4. `Controversy map`: 不一致结论、未验证假设、负面结果或方法分歧。
5. `Knowledge gaps`: 数据、验证、机制、基准或临床转化缺口。
6. `Candidate figures`: 综述图、机制图、证据阶梯、方法路线图或 benchmark 表。

写作规则：

- 不按论文逐篇堆叠，除非本节目标是方法清单。
- 每一节回答一个分类问题或争议问题。
- 综合判断要标为作者综合，不要伪装成某篇文献原话。
- 强主张必须进入 claim-evidence map。
