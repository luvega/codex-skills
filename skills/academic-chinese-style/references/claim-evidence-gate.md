# Claim-Evidence Gate

任何 Abstract、Introduction、Results、Discussion、Conclusion 中的主张，都要进入 claim-evidence map。

格式：

```text
Claim: ... | Evidence: ... | Status: supported/partial/needs evidence/unsupported
```

Evidence 可以是：

- figure/table/panel locator;
- experiment or metric;
- literature citation;
- dataset or cohort;
- figure evidence passport locator;
- user-provided source note.

门禁规则：

- `supported`: 证据直接支持主张。
- `partial`: 证据支持方向，但范围或机制仍有限。
- `needs evidence`: 需要作者补充图表、结果、引用或数据来源。
- `unsupported`: 当前材料不支持，应删除或降级。

写作时不要把 `partial` 改写成确定性结论。
