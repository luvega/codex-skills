# Paragraph Flow Rules

一段只服务一个信息。检查顺序：

1. 该段第一句是否说明段落任务。
2. 每个关键名词是否自足，读者是否不需要隐藏上下文。
3. 相邻句之间是否存在明确关系：原因、转折、递进、结果、例证或限定。
4. 是否混入另一个段落才应处理的信息。
5. 是否存在空泛评价，如“重要意义”“广泛关注”“深入研究”。

Reverse outline:

- 写出本节 thesis。
- 提取每段 topic sentence。
- 在 topic sentence 下列证据或解释点。
- 删除或改写无法映射到 thesis 的段落。

中文处理：

- 长句中同时出现两个独立判断时拆句。
- 同一概念只保留一个中文译名。
- 避免为了“高级感”堆叠抽象名词。
