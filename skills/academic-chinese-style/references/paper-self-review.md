# Paper Self-Review

投稿前按审稿人视角检查五类问题：

1. Contribution: 贡献是否具体、可验证、没有夸大。
2. Clarity: 题目、摘要、引言和图件是否让读者快速理解故事。
3. Experimental Strength: 关键结论是否有足够实验和统计支撑。
4. Evaluation Completeness: 是否缺少必要对照、消融、稳健性或外部验证。
5. Method Soundness: 方法设计、参数、数据处理和复现信息是否完整。

输出格式：

```text
Risk: ...
Reviewer concern: ...
Evidence status: supported/partial/needs evidence/unsupported
Recommended revision: ...
Priority: P0/P1/P2
```

P0 表示可能导致拒稿或科学错误的问题；P1 表示下一轮修改应解决；P2 表示表达或补充材料优化。
