# Related Work Writing Guide

相关工作不是文献堆叠，而是为本文定位坐标。默认分层：

1. 按问题、方法、数据类型或证据层级分组。
2. 每组先给主题句，再列代表性工作。
3. 写清已有工作解决了什么，也写清尚未解决什么。
4. 最后回到本文定位：本文继承、区别或补足哪一层。

规则：

- 不把多篇文献揉成无来源的大结论。
- 不用贬低式表达描述前人工作。
- 引用标记、BibTeX key、Zotero key 和 EndNote 来源名必须原样保留。
- 若文献证据只是相关性，不改写成因果机制。

输出时可按 `主题 -> 已有证据 -> 局限 -> 本文位置` 组织。
